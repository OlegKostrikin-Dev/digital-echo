# Ответы ИВЦ: подходы к работе с данными

> Ответы ИВЦ на вопросы раздела 8 нашего черновика
> [«Как мы предлагаем работать с данными»](proposal-anonymized-data.md).
> Перенесено в репозиторий из проектного документа (docx, июль 2026).

| № | Вопрос | Ответ ИВЦ |
|---|---|---|
| 1 | Какие документы кроме ЭСФ вы можете предоставлять (СНТ, акты выполненных работ, другие)? Что в них есть — стороны, сумма, дата? | На текущем этапе для расчёта индекса локализации целесообразно использовать данные электронных счетов-фактур (ЭСФ), также данные по импорту товаров и услуг: заявления о ввозе товаров (1-ТС) для стран ЕАЭС, декларации на товары (ДТ) для импорта из третьих стран и сведения по НДС за нерезидента для импорта услуг. Использование СНТ не рассматривается, так как структура данных не совсем корректна в текущей редакции. |
| 2 | Можете ли разложить суммы по корзинам с шириной в процентах (5% или 10%)? | Технически формирование диапазонов сумм возможно. Конкретные параметры формирования корзин (5%, 10% либо иной вариант) предлагается определить совместно после оценки влияния на точность расчёта показателей и степень защиты конфиденциальной информации. |
| 3 | Можете ли шифровать стороны стабильно — одна компания всегда одинаково, в том числе между выгрузками? | Да. Технически возможно применять устойчивое одностороннее хэширование, при котором одной организации всегда соответствует один и тот же обезличенный идентификатор, сохраняющийся между всеми выгрузками. |
| 4 | Есть ли в данных признак «резидент/нерезидент» по сторонам сделки? | Да. Возможность определения признака резидентности участников сделки имеется и может быть включена в состав передаваемых данных после согласования состава атрибутов. |
| 5 | Реально ли отдавать данные по каждому документу с датой (а не свёрнутыми за период)? | Да. Технически такая выгрузка возможна, однако необходимо учитывать, что объём передаваемых данных может быть значительным и зависит от выбранного периода. |
| 6 | Какой объём и периодичность реальны? Ориентир — порядка миллиона документов в день. | ИВЦ располагает необходимой вычислительной инфраструктурой для обработки и формирования выгрузок большого объёма данных. Обработка порядка нескольких миллионов документов в сутки технически реализуема. Периодичность передачи данных (ежедневно, еженедельно либо по иному регламенту) предлагается определить совместно с учётом требований проекта. |
| 7 | Подходит ли схема с отпечатком программы и подписью выгрузок? | Просим предложить предпочтительные варианты реализации, например электронная цифровая подпись, криптографическое хэширование файлов либо иные механизмы. Конкретный способ будет определён совместно на этапе проектирования обмена данными. |

## Сводка: что согласовано, что открыто

**Подтверждено ИВЦ:**

- стабильное одностороннее хэширование сторон сделки (вопрос 3);
- признак резидентности в составе атрибутов (вопрос 4);
- подокументная выгрузка с датами (вопрос 5);
- объёмы порядка миллионов документов в сутки (вопрос 6);
- корзины сумм с процентной шириной — технически возможны (вопрос 2).

**Скорректировано ИВЦ:**

- состав источников: ЭСФ + импорт (заявления 1-ТС по ЕАЭС, декларации на
  товары по третьим странам, НДС за нерезидента по импортным услугам);
  СНТ исключены из-за некорректной структуры данных (вопрос 1).

**Открытые пункты (мяч на нашей стороне):**

- ширина корзины (5% / 10% / иная) — определить после оценки влияния на
  точность; план: прогнать «коридор погрешности» (шаг 4 из черновика) на
  тестовом графе движка и предложить обоснованное значение;
- механизм подписи выгрузок и отпечатка программы (вопрос 7) — ИВЦ ждёт
  наше предложение по конкретной реализации.
